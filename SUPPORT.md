# Support

For help using a blueprint:

- Read its **Before you start**, **Set it up**, **Try it**, and **Safety** sections.
- Search existing issues for a similar question.
- Open an issue with the **Bug Report** form when an existing example does not work. Include the blueprint, steps, and redacted errors.
- Use **Blueprint Request** to suggest a new use case.

Never include tokens, credentials, private keys, connection strings, or sensitive repository data in an issue. For a suspected security vulnerability, follow [SECURITY.md](SECURITY.md) instead of filing a public issue.

This is a community project and support is provided on a best-effort basis.
