# Blueprints

Blueprints are grouped by experience level. Start with **Beginner**.

| Level | For | What to expect |
| --- | --- | --- |
| [Beginner](beginner/) | First agentic workflow | One file, copy and compile, no settings to change. Read-only, one comment or issue per run. |
| [Intermediate](intermediate/) | Comfortable with Beginner | Labels, manual inputs, and settings you tailor to your team. *Coming soon.* |
| [Expert](expert/) | Running agentic workflows in production | Multiple steps, external systems, and stricter guardrails. *Coming soon.* |

Every blueprint is a single gh-aw Markdown file. You copy it into your repository's `.github/workflows/` folder, compile it with `gh aw compile`, and commit both files. See [Running workflows](../docs/running-workflows.md).
