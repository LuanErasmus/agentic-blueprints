## Issue example

**Title:** Cancellation button reports an error

### Expected behaviour
Customers can request cancellation before dispatch.

### Actual behaviour
The page displays an error, but the order status changes to cancelled.

### Steps to reproduce
1. Open a pending order.
2. Select Cancel.
3. Compare the page message with the order status.

### Context
Observed in the demonstration environment. Related work: #12.
