# Learn and get started

Choose a path rather than reading everything in order.

| Your goal | Guide |
| --- | --- |
| Understand agentic workflows | [What Is Agentic?](what-is-agentic.md) |
| Install an existing workflow | [Getting Started](getting-started.md) |
| Check triggers, authentication, costs, and safety | [Running Workflows](running-workflows.md) |
| Build your own with Copilot | [Skills, agents, and instructions](../skills-and-agents/) |
| Understand reusable designs | [Patterns](patterns/) |
| Contribute a reusable blueprint | [Creating a Blueprint](creating-a-blueprint.md), then [the README template](templates/blueprint-template/) |

For a first workflow, follow **Getting Started → the chosen blueprint's README → Running Workflows** as needed. For your own workflow, start with the Copilot helpers; this collection's blueprint contribution rules do not constrain your project.
