# Copilot agents

Use the [Agentic Workflow Builder](agentic-workflow-builder.agent.md) when you want help creating or adapting your own workflow.

Copy it to `.github/agents/agentic-workflow-builder.agent.md` in your repository. Select **Agentic Workflow Builder** in your supported client's custom-agent picker, then describe the task:

> Create a weekly workflow that reports one verified documentation gap in an issue. Include setup instructions and validate the source without running it live.

The agent follows your project's requirements, not this collection's blueprint packaging rules.
