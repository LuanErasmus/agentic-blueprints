# Copilot instructions

Use instructions for baseline guidance when Copilot edits your agentic workflow Markdown. They apply to matching files automatically on supported surfaces; you do not select them as an agent.

Copy [agentic-workflows.instructions.md](agentic-workflows.instructions.md) to `.github/instructions/agentic-workflows.instructions.md` in your repository. Its `applyTo` pattern covers `.github/workflows/*.md`; adjust it if needed.

Then open or attach a workflow and ask:

> Update this workflow's schedule while preserving its permissions and output boundaries. Follow the repository's agentic-workflow instructions.
